倒计时工具 — 使用说明（Windows）
================================

一、正确安装
------------
1. 将本 zip【完整解压】到固定文件夹，例如：
     D:\Apps\count_down_tool\
2. 进入解压后的文件夹，双击运行：
     count_down_tool.exe
3. 请保留与 exe 同目录下的其它文件/文件夹（常见为 _internal）。
   它们是程序运行所需的组件，删除或只拷贝单个 exe 会导致无法启动。

【请勿】
  · 在压缩包窗口内直接双击运行
  · 只从 zip 中拖出 count_down_tool.exe 单独使用
  · 把 exe 与旁边的依赖文件夹拆开、分开存放


二、若提示「来自网络」或无法打开
--------------------------------
1. 右键 count_down_tool.exe → 属性
2. 若有「解除锁定」，勾选后确定
3. 再重新运行


三、常见错误：Failed to load Python DLL / 找不到 python311.dll
--------------------------------------------------------------
多见于旧版「单文件 exe」或只拖出 exe 未带依赖。
请改用本包【完整解压】后的目录运行；不要使用旧的单独 exe。
可删除 %TEMP% 下名称以 _MEI 开头的临时文件夹后重试。


四、配置保存在哪里
------------------
主题、音效、窗口位置等用户配置不在程序目录，而在：

  %APPDATA%\count_down_tool\config.json

（资源管理器地址栏输入 %APPDATA%\count_down_tool 即可打开）

自定义音效备份：同目录下的 sounds\ 文件夹。
更新程序一般不会覆盖上述配置。

运行日志（排查问题时请附上）：
  %APPDATA%\count_down_tool\app.log
  （体积过大时会自动轮转为 app.log.1 / app.log.2）
  需要更详细日志时，启动前可设置环境变量：
    COUNT_DOWN_TOOL_LOG_LEVEL=DEBUG


五、基本使用
------------
· 设置到期时间或使用快捷预设 → 开始倒计时
· 运行中 / 暂停中：不可改时间与预设
· 标题栏 ⚙：打开设置中心
· Esc：隐藏到系统托盘
· M：切换 Mini 小组件
· T：切换透明（Mini）
· 真正退出：托盘图标右键 → 退出

若看不到托盘图标：请查看任务栏「显示隐藏的图标」；
或使用完整窗口标题栏的 ⚙ 打开设置。


六、自动更新说明
----------------
有新版本时，可在设置 → 关于 中检查更新。
更新会替换程序目录中的文件；请仍保持「整目录」使用，不要只保留单个 exe。

从很旧的单文件版本升级时，若自动更新后无法启动，
请到 GitHub Releases 重新下载最新 zip 并完整解压覆盖。
